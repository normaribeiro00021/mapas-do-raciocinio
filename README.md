# Mapas do Raciocínio

Vamos criar uma página de vendas para um infoproduto seguindo a matéria-prima da oferta que está no arquivo em anexo.

REGRA FIXA: Essa página de vendas deve ser feita 100% para mobile-first e super otimizada para rapidez no connect rate.

IMPORTANTE: A página será no idioma "PORTUGUÊS-BR" buscando a proximidade com a linguagem utilizada pela população local do país.

Você deve usar a matéria-prima da oferta em anexo que contém todas as informações da oferta para criar a página completa, seguindo toda a estrutura das dobras, DNA visual (cores, tipografia, tom visual editorial científico), os 6 módulos, os 60 mapas, as situações comparativas da Big Idea, o mecanismo de raciocínio contextual, FAQ em acordeão e CTA persuasivo.
